# Piper-L π0.5 + RLT

此入口使用 Yyshadow/openpi-RLT 的原始 RLTokenModel、ChunkActor、TwinCritic 和 actor-critic 更新实现。源码固定在 `c1e40ac360185778c98cf20da2820e22d2d415e7`，保留 Apache-2.0 许可证和来源记录。Piper 接口位于独立 `rlt_piper/`；原π0.5、VPP2、Corrector入口不变。本次用户选择先不用Corrector，因此此入口不加载其权重、不运行其监控或引导。

## 已有模型与训练阶段

基础模型始终为当前2500更新的π0.5，50步、30Hz、六关节弧度和绝对夹爪米。主干冻结，不覆写原权重。Token读取冻结VLA最终Transformer的两路有效图像前缀（512×2048）；固定屏蔽的第三路图像被移除，语言/状态仍参与前缀注意力。使用上游Encoder/Decoder训练512维Token。

离线准备使用原48训练/6验证的整段划分，每6帧取一个不跨episode的锚点，八H100提取后训练Token1000步。留出重构MSE为0.659724，初始22.1516；该验证集不构成RL成功率证据。此阶段不训练在线actor，不执行机械臂。Token完成后训练进程退出并释放显卡。

在线学习则在.102单5090执行：18步chunk actor-critic，沿用上游固定标准差高斯actor、双Q、参考动作dropout及目标网络更新。先收集至少600个有效标记transition，先用2000步BC主导的warmup（Q权重0），之后Q权重0.1、BC权重5。默认每个新标记回合后更新2000步；新数据不足或没有新增回合时等待，不虚构奖励、不执行随机初始化actor。上游Ethernet默认chunk10/20Hz；本适配为18/30Hz以匹配现有RTC，并非原论文数值的逐项复现。

## 命令

在.102部署目录中，首次采集运行：

```bash
./run_pi05_rlt.sh --stage collect
```

此命令会自动准备、对齐并开始真实动作。`collect`执行原π0.5参考动作，同时提取RL Token和记录实际命令；此时没有训练好的actor在控制。S标记成功、F标记失败；两者结束本轮并阻尼停止，保存数据后按条件训练。Space/Esc/Ctrl+C始终是独立阻尼急停，未标记的急停回合不进入RL训练。S/F从X11读取，不抢占原急停键盘的终端输入。

有经过真实标记回合训练的actor后，可运行 `./run_pi05_rlt.sh --stage online`，使用上游高斯actor进行在线探索，每轮标记后更新；`./run_pi05_rlt.sh --stage eval` 使用确定性actor均值且不更新。缺actor文件、版本0或Token不匹配时拒绝进入这两种模式，绝不偷偷回退并宣称RLT已启用。

`--no-train`只收集不自动训练。手动触发模型学习可以执行：

```bash
PYTHONPATH=. .venv/bin/python -m rlt_piper.cli train
```

仅保存观测的GPU检查：`./check_pi05_rlt.sh --stage collect`。该检查取得共享锁，但不打开CAN/相机、不使能机械臂；自身启动的模型进程会在结束时退出。真实执行结束后也退出自身RLT模型，避免额外驻留显存。

## 执行与回放语义

使用既有RTC Timeline、18帧有效前缀、12帧速度衔接和50ms持续滤波，120Hz发指令，保留固件限位/指令限速与独立阻尼监督器。推理耗时包含基础VLA、Token提取和actor；当前特征提取另做一次冻结前缀前向，后续可优化共享KV缓存，不能假定等于原π0.5延迟。

录制数据位于私有 `rlt_episodes/`，包括接受的预测、原始actor输出、参考动作、Token、状态、源标签，以及每次实际发送后记录的命令和单调时钟。学习时按30Hz重建实际执行序列，保留终止窗口有效长度；补齐尾部只作为模型输入约定，不计为真的发送或环境交互。缺标记、缺终止观测、反馈/键盘异常、跨代际和未来混入Corrector恢复的窗口不用于学习。数据绑定Token身份和RTC/滤波设置；更换设置后不能混用已有learner。

Token、actor和重放数据分别放在 `rlt_assets/pi05_2500`、`rlt_episodes`，均不提交Git。仅实现及无硬件回放不能证明在线策略提高抓取成功率，仍需真机采集和对照评估。

## 无硬件验证（2026-11-13）

.102 RTX5090保存观测检查10次请求通过：中位142.8ms、P95 145.2ms，包含π0.5和RL Token提取，不包含已学会任务的actor。20秒真实RPC加120Hz软件机械臂回放通过，139个chunk、2368次软件指令，最大指令间隔10.37ms；图像和状态重复使用保存样本、时戳是模拟采集锚点，未打开硬件，也不写正式RL回放。

单5090的合成数据学习检查完成4次梯度步、2次actor更新，actor参数实际改变、输出有限，训练状态可序列化并恢复。此检查不保存正式actor，也不能作为策略效果证据。S/F读取器已验证可打开桌面X11；真实按键到机械臂阻尼停止的整条物理链路仍需操作时确认，独立急停实现保持原样。
